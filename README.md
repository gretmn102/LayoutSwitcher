# LayoutSwitcher

Bash скрипты для преобразования текста, набранного раскладкой ЙЦУКЕН, в английскую QWERTY.

## Установка для Termux

Склонировать проект:

```bash
git clone https://github.com/gretmn102/LayoutSwitcher.git
cd LayoutSwitcher/
```

Скопировать в `$PREFIX/bin` и дать права:

```bash
cp switch-ru-to-en.sh $PREFIX/bin/switch-ru-to-en
chmod u+x $PREFIX/bin/switch-ru-to-en

cp iswitch-ru-to-en.sh $PREFIX/bin/iswitch-ru-to-en
chmod u+x $PREFIX/bin/iswitch-ru-to-en
```
